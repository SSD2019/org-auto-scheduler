* Org Auto Scheduler

Org Auto Scheduler is an Emacs plugin that automatically schedules tasks in your Org mode files based on various factors such as priority, deadline, effort, and custom time blocks.

** Features

- Automatically schedules tasks with the =AUTOSCH= tag
- Considers task priority, deadline, effort, and current state
- Supports custom time blocks for specific tags
- Respects existing scheduled tasks and avoids conflicts
- Customizable scheduling parameters
- Handles project-based task grouping and ordering
- Considers clocked time when calculating remaining effort

** Usage

To use Org Auto Scheduler, add the =AUTOSCH= tag to any task you want to be automatically scheduled. Then run the command:

=M-x org-auto-scheduler-schedule-tasks=

You can also bind this command to a key combination, for example:

=(global-set-key (kbd "C-c a s") 'org-auto-scheduler-schedule-tasks)=

** Customization Options

*** General Settings

- =org-auto-scheduler-start-time=: Start time for scheduling tasks (default: "09:00")
- =org-auto-scheduler-end-time=: End time for scheduling tasks (default: "17:00")
- =org-auto-scheduler-task-gap=: Gap between scheduled tasks in minutes (default: 5)
- =org-auto-scheduler-max-days-to-check=: Maximum number of days to look ahead for scheduling (default: 14)
- =org-auto-scheduler-time-interval=: Interval in minutes for checking time slots (default: 15)
- =org-auto-scheduler-excluded-days=: List of days to exclude from scheduling (0 is Sunday, 6 is Saturday)

*** Scoring Weights

- =org-auto-scheduler-effort-weight=: Weight for remaining effort in score calculation (default: 0.0)
- =org-auto-scheduler-priority-weight=: Weight for priority in score calculation (default: 10.0)
- =org-auto-scheduler-urgency-weight=: Weight for urgency factor in score calculation (default: 20.0)
- =org-auto-scheduler-urgent-days=: Number of days before a deadline is considered urgent (default: 7)

*** Task States

- =org-auto-scheduler-state-weights=: Alist of weights for different TODO states
  Default: =(("TODO" . 0) ("NEXT" . 1) ("IN-PROGRESS" . 2) ("WRITE" . 0) ("LATER" . -10) ("BUY" . 0) ("READ" . 0))=

*** Time Blocks

- =org-auto-scheduler-time-blocks=: Alist of time blocks for scheduling tasks with specific tags
  Default:
  #+begin_src emacs-lisp
  '(("FUN" . (("18:00" . "19:00")))
    ("BUYING" . (("14:00" . "15:00")))
    ("CHORES" . (("19:00" . "20:00"))))
  #+end_src

*** Other Settings

- =org-auto-scheduler-inherited-priority-property=: Property name for setting inherited priority for subtasks (default: "INHERITED_PRIORITY")
- =org-auto-scheduler-scheduled-property=: Property name to mark AUTOSCH tasks that have been scheduled in the current session (default: "AUTOSCH_SCHEDULED")
- =org-auto-scheduler-default-task-duration=: Default duration in minutes for tasks without an explicit effort (default: 60)

** How It Works

1. The plugin clears existing scheduled times for tasks with the =AUTOSCH= tag.
2. It collects all schedulable tasks (those with =AUTOSCH= tag and valid TODO states).
3. Tasks are sorted based on a calculated score considering priority, deadline, effort, state, and project grouping.
4. Each task is scheduled in the next available time slot, respecting time blocks if applicable.
5. The plugin avoids conflicts with existing scheduled tasks and maintains gaps between tasks.
6. It considers clocked time when calculating remaining effort for tasks.
7. Project-based tasks are grouped and scheduled together.

** Debugging

To debug the auto-scheduler, use the command:

=M-x org-auto-scheduler-debug=

This will run the scheduler with detailed logging and open the log buffer for inspection.
